# 同勘 GeoCrew 插件

同勘 GeoCrew 的插件目录、插件开发工具包和官方插件。

> 状态：规划中。插件接口随安卓客户端重写一起设计，先以预览版发布，核心稳定后再定 1.0。

## 内容（规划）

- **插件目录**：每个插件一条记录，包括名称、作者、版本、说明、下载地址、文件哈希、所需权限和适用的应用版本。插件代码放在作者自己的仓库里发布；作者提交 PR 把插件加进目录，审核后合并。应用从官方目录、工作组目录（组长在自己的服务端上维护）或本地文件安装插件。
- **开发工具包**：宿主接口的 TypeScript 类型定义、清单格式，以及命令行工具（新建、构建、校验、测试、打包、提交），可以在电脑上用真实的 GDAL 测试插件。
- **官方插件**：官方插件同时也是示例。
- **收录流程**：收录要求、质量指南和审核清单。

插件规范和清单格式定义在主仓库的 [protocol/](https://github.com/GeoCrew-Dev/GeoCrew/tree/main/protocol)。每个插件都要附带和内置功能同一格式的说明书，装上之后同勘的 AI 就能找到并调用它。
